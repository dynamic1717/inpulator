# Input Translate

Chrome-расширение для перевода выделенного текста **с русского на английский** прямо в полях ввода — без переключения на отдельный переводчик.

## Зачем

Пишете сообщение на английском, но удобнее набрать мысль по-русски? Обычный флоу: написать → открыть переводчик → скопировать → вставить. Input Translate сокращает это до **выделить → нажать кнопку**.

## Возможности

- **Перевод выделения на месте** — текст заменяется прямо в поле ввода
- **Плавающая кнопка** — появляется рядом с выделением, только если в тексте есть кириллица
- **Счётчик на кнопке** — формат `126/4565`: символов в выделении / оставшийся дневной лимит (локальный)
- **Горячая клавиша** `Alt+Shift+T` — перевод без клика по кнопке
- **Поддержка полей ввода:**
  - `<input>`, `<textarea>`
  - `contenteditable` (Gmail, ChatGPT, Claude и др.)
- **Shadow DOM** — работа через обход дерева от selection
- **Fallback через буфер обмена** — если прямая замена текста не сработала
- **Состояния UI** — загрузка (спиннер), ошибки (toast)

## Как пользоваться

1. Введите текст на русском в любое поддерживаемое поле
2. Выделите фрагмент для перевода
3. Нажмите на кнопку с иконкой перевода **или** `Alt+Shift+T`
4. Выделение заменится английским переводом

Кнопка исчезает, когда выделение снято.

## Горячая клавиша

| Действие            | Комбинация    |
| ------------------- | ------------- |
| Перевести выделение | `Alt+Shift+T` |

Переназначить: `chrome://extensions/shortcuts`

## Лимиты перевода

Используется бесплатный [MyMemory API](https://mymemory.translated.net/):

|                   |                                                     |
| ----------------- | --------------------------------------------------- |
| Лимит             | **50 000 символов/день**                            |
| Счётчик на кнопке | Локальная оценка остатка (сбрасывается каждый день) |
| Исчерпан лимит    | Сообщение «Daily translation limit exceeded»        |

Точный остаток API не отдаёт — только флаг `quotaFinished` при исчерпании.

## Ограничения

- Только **RU → EN**
- Кнопка не появляется без кириллицы в выделении
- Не работает в **cross-origin iframe**
- **Rich text** — вставляется plain text, форматирование теряется
- **Качество перевода** — среднее (достаточно для сообщений, не для юридических текстов)
- Текст отправляется на внешний сервер MyMemory
- После обновления расширения **перезагрузите вкладку** (F5)

## Установка

### Из исходников (для себя)

1. Скачайте или клонируйте репозиторий
2. Откройте `chrome://extensions`
3. Включите **Режим разработчика**
4. **Загрузить распакованное расширение** → выберите папку проекта
5. При запросе разрешите доступ к clipboard (для fallback)

### Обновление

1. `chrome://extensions` → кнопка обновления у расширения
2. Перезагрузите открытые вкладки

## Приватность

- Переводимый текст передаётся в MyMemory API
- Локально хранится только счётчик использованных символов за день (`chrome.storage.local`)
- Расширение для **личного использования**
