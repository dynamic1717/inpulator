# Input Translate

Chrome-расширение для перевода выделенного текста **с русского на английский** прямо в полях ввода — без переключения на отдельный переводчик.

## Зачем

Пишете сообщение на английском, но удобнее набрать мысль по-русски? Обычный флоу: написать → открыть переводчик → скопировать → вставить. Input Translate сокращает это до **выделить → нажать кнопку**.

## Возможности

- **Перевод выделения на месте** — текст заменяется прямо в поле ввода
- **Плавающая кнопка** — появляется рядом с выделением, только если в тексте есть кириллица
- **Провайдеры** — Chrome Translator (по умолчанию, on-device), Google Translate, MyMemory
- **Счётчик на кнопке** — `126/4 565` или `126/∞` для Chrome; можно скрыть
- **Окно настроек** — клик по иконке: лимит, провайдер, вкл/выкл, счётчик на кнопке
- **Горячая клавиша** `Alt+Shift+T` — перевод без клика по кнопке
- **Поддержка полей ввода:**
  - `<input>`, `<textarea>`
  - `contenteditable` (Gmail, ChatGPT, Claude и др.)
- **Shadow DOM** — работа через обход дерева от selection
- **Fallback через буфер обмена** — если прямая замена текста не сработала
- **Состояния UI** — загрузка (спиннер), ошибки (toast)

## Как пользоваться

1. Введите текст на русском в любое поддерживаемое поле
2. Выделите фрагмент для перевода
3. Нажмите на кнопку с иконкой перевода **или** `Alt+Shift+T`
4. Выделение заменится английским переводом

Кнопка исчезает, когда выделение снято.

Настройки: клик по иконке расширения — лимит, провайдер, глобальный вкл/выкл (иконка становится серой), счётчик на кнопке.

## Провайдеры и лимиты

| Провайдер         | Лимит (локальный)   | Примечание                                               |
| ----------------- | ------------------- | -------------------------------------------------------- |
| Chrome Translator | **Без лимита**      | По умолчанию; on-device, Chrome 138+ desktop             |
| Google Translate  | **500 000 / месяц** | Fallback, если Chrome недоступен; нужен API key в `.env` |
| MyMemory          | **50 000 / день**   | Fallback при исчерпании лимита Google                    |

Цепочка при провайдере Chrome: Chrome → Google (если доступен и есть quota) → MyMemory.

Точный остаток облачных API не отдаётся — счётчики Google/MyMemory локальные в `chrome.storage.local`.

## Ограничения

- Только **RU → EN**
- Chrome Translator: **Chrome 138+ desktop** (не mobile); первый вызов может скачать language pack
- Кнопка не появляется без кириллицы в выделении
- Не работает в **cross-origin iframe**
- **Rich text** — вставляется plain text, форматирование теряется
- При облачных провайдерах текст уходит на Google Cloud Translation и/или MyMemory
- После обновления расширения **перезагрузите вкладку** (F5)

## Установка

### Из исходников (для себя)

1. Скачайте или клонируйте репозиторий
2. Скопируйте `.env.example` → `.env` и заполните:
   - `GOOGLE_TRANSLATE_API_KEY` — ключ [Cloud Translation API](https://cloud.google.com/translate/docs/basic/translating-text)
   - `MYMEMORY_EMAIL` — email для повышенного лимита MyMemory
3. `npm install && npm run env` — сгенерирует `env.js`
4. Откройте `chrome://extensions`
5. Включите **Режим разработчика**
6. **Загрузить распакованное расширение** → выберите папку проекта
7. При запросе разрешите доступ к clipboard (для fallback)

### Обновление

1. При смене `.env` снова выполните `npm run env`
2. `chrome://extensions` → кнопка обновления у расширения
3. Перезагрузите открытые вкладки
