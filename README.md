# Inpulator

Chrome-расширение для перевода выделенного текста **с русского на английский** прямо в полях ввода — без переключения на отдельный переводчик.

## Зачем

Пишете сообщение на английском, но удобнее набрать мысль по-русски? Обычный флоу: написать → открыть переводчик → скопировать → вставить. Inpulator сокращает это до **выделить → нажать кнопку**.

## Возможности

- **Перевод выделения на месте** — текст заменяется прямо в поле ввода
- **Плавающая кнопка** — появляется рядом с выделением, только если в тексте есть кириллица
- **Провайдеры** — Chrome Translator (по умолчанию, on-device), Google Translate, MyMemory
- **Счётчик на кнопке** — `126/4 565` или `126/∞` для Chrome; можно скрыть
- **Окно настроек** — клик по иконке: лимит, провайдер, личный Google API key, вкл/выкл, счётчик на кнопке
- **Горячая клавиша** `Alt+Shift+T` — перевод без клика по кнопке
- **Поддержка полей ввода:**
  - `<input>`, `<textarea>`
  - `contenteditable` (Gmail, ChatGPT, Claude и др.)
- **Shadow DOM** — работа через обход дерева от selection
- **Fallback через буфер обмена** — если прямая замена текста не сработала
- **Состояния UI** — загрузка (спиннер), ошибки (toast)

## Как пользоваться

1. Введите текст на русском в любое поддерживаемое поле
2. Выделите фрагмент для перевода
3. Нажмите на кнопку с иконкой перевода **или** `Alt+Shift+T`
4. Выделение заменится английским переводом

Кнопка исчезает, когда выделение снято.

Настройки: клик по иконке расширения — выберите провайдера, посмотрите его лимит, при необходимости добавьте личный Google API key, настройте исключённые сайты, глобальный вкл/выкл и счётчик на кнопке.

| Перевести выделение | `Alt+Shift+T` |

Переназначить: `chrome://extensions/shortcuts`

## Провайдеры и лимиты

| Провайдер         | Лимит (локальный)   | Примечание                                   |
| ----------------- | ------------------- | -------------------------------------------- |
| Chrome Translator | **Без лимита**      | По умолчанию; on-device, Chrome 138+ desktop |
| Google Translate  | **500 000 / месяц** | Нужен личный API key, введённый в настройках |
| MyMemory          | **50 000 / день**   | Облачный сервис, текст передаётся MyMemory   |

Расширение всегда использует только выбранный провайдер. Если он недоступен или его лимит исчерпан, выберите другой провайдер в настройках.

Точный остаток облачных API не отдаётся — счётчики Google/MyMemory локальные в `chrome.storage.local` и являются оценкой.

## Ограничения

- Только **RU → EN**
- Chrome Translator: **Chrome 138+ desktop** (не mobile); сначала скачайте language pack через popup
- Кнопка не появляется без кириллицы в выделении
- Не работает в **cross-origin iframe**
- **Rich text** — вставляется plain text, форматирование теряется
- При облачных провайдерах текст уходит на Google Cloud Translation и/или MyMemory
- После обновления расширения **перезагрузите вкладку** (F5)

## Установка

### Из исходников (для себя)

1. Скачайте или клонируйте репозиторий
2. Выполните `npm install`
3. Откройте `chrome://extensions`
4. Включите **Режим разработчика**
5. **Загрузить распакованное расширение** → выберите папку проекта
6. Для Google Translate создайте личный ключ [Cloud Translation API](https://cloud.google.com/translate/docs/basic/translating-text), ограничьте его Translation API и квотой, затем добавьте в popup.

### Обновление

1. `chrome://extensions` → кнопка обновления у расширения
2. Перезагрузите открытые вкладки

## Приватность

- Переводимый текст передаётся только выбранному пользователем облачному провайдеру: Google Cloud Translation или MyMemory
- Локально: счётчики usage, настройки и личный Google API key (`chrome.storage.local`)
- Не передавайте API key другим людям; ограничьте его Cloud Translation API и квотами
- Расширение для **личного использования**
